# Queryflow development guidance

Read `docs/V6_4_SPEC.md`, `docs/V6_4_MATRIX.md`, and `docs/V6_4_PROGRESS.md` before V6.4 changes. Preserve read-only SQL, allowlisted database access, bounded model/database calls, and the accepted conversation state. Do not mark a requirement VERIFIED without a relevant passing test. Do not include local `.env`, database files, or untracked screenshots in commits. The current implementation is incomplete; use the progress file to resume from the next unverified requirement.
